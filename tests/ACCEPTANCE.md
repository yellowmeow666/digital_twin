# 数字孪生 MVP · 手工验收清单

在仓库根目录执行：

```bash
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080 ，按下列项逐条勾选。不要安装 npm / Playwright。

## 清单（MVP）

- [ ] 用 `python3 -m http.server 8080` 启动后，浏览器能打开页面（无空白页、无致命报错）
- [ ] 页面可见 3D 场景，且可用鼠标拖拽做轨道旋转（orbit）
- [ ] 场景中有 **4** 个可点选设备
- [ ] 点选任一设备后，侧栏显示该设备的**名称**、**状态**、**指标**
- [ ] 选中设备后，指标大约每 **2 秒**会变化（观察至少两轮更新）
- [ ] 未选中任何设备时，侧栏有占位内容（不是空白/报错）

## 清单（迭代2）

- [ ] 左侧设备名单支持**搜索/过滤**（输入关键字后名单变少，清空后恢复）
- [ ] **点击左侧名单**某项，可选中对应设备（侧栏与场景高亮同步）
- [ ] 指标**越限**后出现告警态（文案和/或设备变色；观察可复现）
- [ ] 选中设备后，侧栏有**历史走势**（可见折线/走势区域，随时间有更新）
- [ ] 点选或定位操作会**飞相机**到目标设备（视角明显过渡到该设备附近）

## 清单（迭代3 · 视觉）

- [ ] 首屏打开有**开场推镜**（相机从远处平滑推近到厂房全景）
- [ ] 厂房有**墙、柱、梁**和**地面标线**
- [ ] 四类设备（水泵、储液罐、传送带、装配机器人）模型**能辨认出是什么**
- [ ] **传送带会动**（皮带/滚筒有可见运动）
- [ ] **机械臂会摆**（装配机器人手臂有持续摆动）
- [ ] 有**反射和阴影**质感（设备在地面有投影，金属/地面有反射感）
- [ ] 选中设备时有**描边发光**
- [ ] 告警设备有**光圈**（脉动或环形高亮）
- [ ] 设备**头顶有名牌**（名称标签跟随设备）
- [ ] 帧率**主观流畅**：旋转、缩放、定位飞行时不卡顿
- [ ] **回归**：MVP 六条与迭代2五条全部仍然正常
- [ ] 首屏截图已提交到 `docs/screenshot.png`
